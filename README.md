# Çalışma Uygulaması

Bu sürümde uygulama açılışta ders seçtirir:

- Tarih
- Din Kültürü

Seçilen derse göre aynı çalışma akışı devam eder:

- Konu bazlı çalışma
- Tüm konuları karışık tekrar
- Yanlış yapılan soruları tekrar çalışma
- Tek seferlik istatistik ve zayıf konu takibi

## Çalıştırma

```bash
npm install
npm run dev
```

Aynı modemden erişmek için terminalde görünen Network adresini kullan.
